# Digest 024 - React Game Application (234 lines, fully read)

## 1. Purpose
Single-page desktop React + ThreeJS app: orthographic isometric voronoi/square map, click-to-inspect, government commands, build/zone tools, content browser, inventory, status/flow, standing orders, settlement progress, citizen identity/chronicle, housing. Pure view layer over the headless engine in the same browser context (state out, commands in).

## 2. Implied layout and renderer<->engine boundary
```
src/renderers/react/            (README required in every folder, 023)
  main.tsx, App.tsx, AppShell.tsx (routing: map | content | chronicle | flow | idle-blocked | standing-orders | new-game | settings)
  engine/EngineHost.ts          creates engine (spec 007 bootstrap), owns tick scheduling (rAF/interval, speed), exposes store
  engine/useGameState.ts        subscription hooks (selectors, throttled), event bus bridge (spec 010)
  engine/commands.ts            typed command dispatch wrappers
  map/ MapCanvas.tsx (three), IsoCamera.ts (orthographic, rotate/pan/zoom, touch), TileMesh voronoi+square, EntityModels.ts (humanoid, livestock, wild, furniture, dwelling levels x4, notice post, bell tower), Picking.ts (raycast->tile/entity), PlacementGhost.ts, ZonePainter.ts, WallTool.ts, Culling.ts, Badges.tsx, Interpolation.ts (sub-cell move smoothing)
  panels/ InspectionPanel, EntityPanel, TilePanel, ZonePanel, DwellingPanel, CitizenPanel (+Journal tab), InventoryTab, WhyPopover
  views/ ContentBrowser (13 registries + read-only config tables), FlowView, IdleBlockedList, StandingOrdersPanel, ChronicleView, SettlementProgressPanel, CommandPanel (pending list), BuildMenu, ZoneTypePicker, NewGameScreen, SaveLoadMenu, Toasts, Breadcrumb
  prefs/ renderer preferences (toast settings, toastBurstLimit default 3, autosave interval) - NOT game state
```
Screens/panels (from spec): (1) Map view with overlays (reason badges, at-risk dwelling flags, pending build sites/blueprints, hover label with styled name, door animation, bell-ring indicator, placement ghost red/valid); (2) Inspection panel (entity/tile/zone; first line = primary status reason + "why?" -> explain(); tabs: state, needs, skills, inventory, faction, zone, BT node, Journal); (3) terrain inspection panel; (4) occupant cycle list for multi-entity tiles; (5) Government command interface (job board pause/resume, trade priorities [unspecified], diplomatic directives, custom jobs on player boards, standing orders CRUD, appoint/dismiss Steward) + pending commands list with progress/ETA/cancel; (6) Build menu (furniture, locked greyed with "Unlocks at <Tier>"); (7) Zone tools: paint, zone-type picker, wall/door tile or drag-rectangle; (8) Content browser: live search across 13 registries, interlinked, reverse links (material -> recipes), locked content browsable; (9) Inventory tab; zone panels aggregate storage furniture inventories; (10) Idle & Blocked list grouped by reason, sorted by sinceTick, click centres camera; (11) Flow view (per material: produced/day, consumed/day, net/day, stock, days of supply, trend, producers w/ badges, expandable FlowSource; sorted largest deficit first); (12) Standing orders panel + "Keep in stock..." prefilled forms from material/inventory/recipe views; Steward board choice; (13) Settlement tier + next-tier requirement progress panel; (14) Notifications (tier/milestone reached, Major chronicle moments, "N more tidings" fold, grouped throttled status.blocked toasts per-reason toggle); (15) Chronicle view (newest first, filter citizen/kind); (16) New-game screen (Peaceful/Steady(default)/Harsh with one-line text); (17) Save/Load UI (file save/load, auto-save interval); (18) Sub-map breadcrumb + back.
Navigation: SPA, no reload; every entity/job/zone/recipe/material reference is a link; preserve browser scroll state.

### Engine API the UI needs (none is specified in one place - must be collected into an engine facade, e.g. src/game/api/GameApi.ts)
Queries/state out: world snapshot + per-tick change notification (subscribe/unsubscribe, selectors, tick number, game time/day); map data (tiles, terrain, voronoi geometry or square grid, sub-maps + parent link, zone membership); entity list in viewport + getEntity(id) (position, kind, activity, needs w/ values, skills w/ levels, inventory, factions, zone, BT active node, task/job ref, styled name/title/offices, journal); picking support (entitiesAtTile, tile at cell); jobs/job boards (status, pause state, pending update); zones (status active/incomplete/ZoneInactive, requirements, aggregated inventory); recipes/content registries read access + reverse-index (recipes using material); explain(subject) + primary status reason + BlockedReasonKind (025); idle/blocked list; flow ledger/FlowSource (025); standing orders list + counters (026); settlement progress getSettlementProgress() (027) + locked/unlocked content flags + tier; difficulty options; chronicle + journal + formatting helper (028); dwelling details + requirement checklist w/ streaks (029); placement validity validatePlacement(furnitureId, cell) -> reasons; event stream: status.blocked, settlement.tier.reached, settlement.milestone.reached, chronicle.moment.recorded, housing.dwelling.upgraded/downgraded/at-risk, bell-tower.rang, jobboard.job.completed; save: serialize(): string/JSON + load(json)/migrations (006), newGame({seed?, difficulty, mapOptions}); tick control: step/run/pause/speed (not in spec).
Commands in (all via engine command queue, deterministic, renderer holds no sim state): pauseJobBoard/resumeJobBoard, postCustomJob, dispatchTownCrier/updateBoard (pending), issueDiplomaticDirective (Envoy, pending), cancelPendingCommand, createStandingOrder/edit/pause/resume/delete, requestStewardReview, appointSteward/dismissSteward/setStewardBoard, placeFurniture (-> ConstructionJob/blueprint), paintZone/createZone/assignZoneType/deleteZone, placeWall/placeDoor (tile or rect), cancelConstruction, save/load/newGame, setTradePolicy (UNDEFINED).

## 3. Functional requirements (condensed)
- FR-001 ThreeJS orthographic isometric camera; rotate/zoom/pan via mouse+touch; tile-aligned raycasting.
- FR-002 Square and voronoi tile modes; default map voronoi.
- FR-003 Terrain tile color/texture by type; frustum culling.
- FR-004 Low-poly models/markers distinguishing humanoid/livestock/wild/furniture; dwelling zones drawn with current-level model.
- FR-005 Click any entity/tile -> raycast selection to correct game object.
- FR-006 Sub-maps (caves, cellars) navigable with breadcrumb + back to parent.
- FR-007 Inspection panel: activity, needs, skills, inventory, factions, zone, active BT node; first line = primary status reason (025 FR-016); citizen styled name/title/offices (028); dwelling housing details (FR-043).
- FR-008 Every entity reference in panels is a navigable link (no reload).
- FR-009 Panels live-update as simulation ticks without re-click.
- FR-010 Command interface: pause/resume job board, trade priorities (undefined), diplomatic directives, custom jobs on player boards, standing-order CRUD, appoint/dismiss Steward.
- FR-011 Physical commands show pending state with dispatched entity's progress.
- FR-012 Player can cancel a pending command.
- FR-013 Build menu from furniture registry; selecting enters placement mode.
- FR-014 Placement ghost snaps to tiles; invalid tiles red; click confirms valid.
- FR-015 Zone tools: paint region, assign type from zone-type registry, walls/doors tile-by-tile or drag-rectangle.
- FR-016 Walls block pathfinding; walls/doors are cell entities drawn on cells (no edge walls); doors passable and animate open/close.
- FR-017 Content browser from any screen covering all 13 registries (config tables optional read-only).
- FR-018 Live text search across all registries simultaneously.
- FR-019 Cross-references in browser are navigable links (recipe->materials; material->consuming recipes).
- FR-020 Inventory tab for inventory entities; zone panels show aggregated storage furniture inventories.
- FR-021 Inventory view live-updates.
- FR-022 Single-page app, no reload navigation.
- FR-023 Playable state within 5 s on modern desktop.
- FR-024 Save/load UI (file save, load picker), optional configurable auto-save; format per spec 006.
- FR-025 Reason badges on every settled Idle/Blocked visible subject; BlockedReasonKind -> modern-English template; "why?" control calls explain() when causeRef.
- FR-026 Idle & Blocked list grouped by reason kind, sorted by sinceTick, click centres camera.
- FR-027 Flow view per material (rates, stock, days of supply, trend, producers, FlowSource breakdown, deficit sort, links).
- FR-028 MAY show grouped throttled toasts for status.blocked; per-reason toggle; renderer prefs not game state.
- FR-029 Standing-orders panel (counted stock, target, restock threshold, in-flight runs by status, state, badge; create/edit/pause/resume/delete; request Steward review).
- FR-030 "Keep in stock..." action on material records, inventory rows, recipe cards; <=3 interactions (026 SC-008).
- FR-031 "Appoint as Steward"/"Dismiss" on citizen panels; choose Steward board.

- FR-033 Notice Post and Bell Tower models; bell-ring indicator on bell-tower.rang.

- FR-035 Locked content greyed with "Unlocks at <Tier>" in build menu, zone picker, production dialogs, standing-order form; not selectable; browsable in content browser.
- FR-036 Notifications for settlement.tier.reached / milestone.reached in flavour style.
- FR-037 New-game screen offers Peaceful, Steady (default), Harsh w/ one-line descriptions.
- FR-038 Styled citizen name everywhere (hover label, panel header, job/trade records); panel shows title rank + offices incl. Steward.
- FR-039 Citizen "Journal" tab via shared formatting helper.
- FR-040 Major chronicle.moment.recorded -> small non-blocking notification (link); > toastBurstLimit (default 3) per game hour folds into "N more tidings"; Minor not notified.
- FR-041 Chronicle view newest-first, filter by citizen/kind, links to existing citizens.
- FR-042 Four distinct low-poly dwelling models (Hovel, Cottage, Timber-Framed House, Burgher House); swap on upgraded/downgraded events.

## 5. Ambiguities / contradictions / missing (blockers [B])
1. [B] No engine facade/query API exists as one contract; UI requirements list ~25 queries/commands across specs. Need a `GameApi` spec (selectors, subscription granularity, snapshots vs events, command envelope with ids/results) before UI work.
2. [B] Tick driving/time controls absent: no pause/speed/step control, who owns the loop in the browser (rAF vs setInterval vs worker), and how determinism is preserved (commands applied at tick boundaries; command timestamp = tick). Also main-thread engine vs Web Worker (assumption says same context; 1000+ tiles + sim may jank, SC-001).
3. [B] Trade priorities/policy undefined (open question; 019 has none). FR-010 "modify trade priorities" and US2 cannot be implemented; drop or define.
4. [B] No build tooling stated: bundler (Vite assumed), react-three-fiber vs raw three, state store (zustand/Redux/useSyncExternalStore), routing lib, UI test stack (RTL/Playwright), CSS approach, dependency list. 023 says static imports/moduleResolution bundler - Vite fits.
5. [B] Voronoi geometry source: how does engine expose cell polygons (spec 004)? Rendering, picking, ghost "whole tile snap" and rect-drag for voronoi cells (rect over irregular cells?) undefined; square mode vs voronoi mode switch is a map property or a UI toggle? Walls "each occupies a whole cell" on voronoi cells.
6. FR-007 "Clicking a *selected* entity or tile opens a panel" vs US1 "click opens"; define select vs inspect (single click select, second click open?).
7. FR-014/US3 "tiles violating constraints red; cannot confirm" vs Edge Case "furniture outside valid zone IS placed with ZoneInactive badge": clarify which constraints are hard (terrain buildable, occupied) vs soft (zone membership). Engine needs validatePlacement returning reason codes.
8. US2 diplomatic directive wording: Envoy delivery pending; player UI for Envoy dispatch path not detailed; standing-orders "Steward board" selection UI unspecified; "custom jobs on player-managed boards" form fields undefined.
9. FR-001 requires touch support but Assumptions say mobile out of scope; define touch as trackpad/tablet only.
10. Performance numbers: SC-001 "stable frame rate" (no fps), US1 3 s vs FR-023/SC-006 5 s load; "within one render frame" (US6) vs "within one simulation tick" (SC-003): define update model (render at rAF reading latest snapshot).
11. Pseudo-old-English flavour text: no copy source defined (templates in content? i18n file?), which strings are flavour vs modern (FR-025 templates modern; notifications flavour); where BlockedReasonKind line templates live (renderer, per 025 FR-015).
12. Model/asset pipeline: "low-poly 3D models, geometric shapes or symbolic markers" - procedural geometry vs glTF assets; not specified; needs minimal set (humanoid, sheep/cow/..., 64 furniture types, 4 dwelling levels, wall, door, notice post, bell tower).
13. Save UI: file download/upload API (File System Access vs blob download); auto-save target (localStorage/IndexedDB vs file) and quota; save versioning/migration surface; seed entry on new game not mentioned though constitution allows seed supply.
14. Settings/preferences persistence (toast settings, autosave interval, camera) location (localStorage) unspecified; "renderer preferences" excluded from saves.
15. Content browser lists 13 registries including behavior trees and name lists - needs a presentation per registry and reverse-link index (derive in renderer or engine?). 200 ms search at 300+ entries trivial.
16. Sub-maps: transition trigger (how player enters a cave/cellar), and whether sim of sub-map runs concurrently; spec 004 coverage unknown.
17. Door animation requires engine to expose door open state/passing events (cosmetic interpolation allowed by 023 clarifications); sub-cell interpolation requires previous-tick positions.
18. FR-016 vs tile-edge wording; FR-004 "Dwelling zones drawn with model of current level" - a zone is an area, model position/anchor undefined.
19. FR-035 gating relies on engine returning unlock status per item; FR-036 "flavour style" templates not supplied.
20. Accessibility, keyboard shortcuts, localisation, browser support matrix: out of scope but undefined.
