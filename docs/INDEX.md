# Documentation index

A map of every document in the repository. The root [README.md](../README.md) is the entry point.

## Principles and decisions

- [CONSTITUTION.md](CONSTITUTION.md): the five principles (engine-renderer decoupling, deterministic JSON state, headless first, scenario snapshots, modular systems) and governance.
- [DECISIONS.md](DECISIONS.md): the contract for implementers. Cross-spec decisions (D-01 to D-30), the canonical tick pipeline, command and event catalogues, spec errata, owner descopes and the implementation decisions D-31 onward made while building.
- [ROADMAP.md](ROADMAP.md): ideas without a spec, and what is descoped for now.

## Understanding and extending the code

- [ARCHITECTURE.md](ARCHITECTURE.md): module map of `src/game`, tick pipeline slots, save format, catalogue pointers, how to add a system, command, query, job type or content entry.
- [PERFORMANCE.md](PERFORMANCE.md): the measurable success criteria, how they are tested, what they cost today, how the hot spots were found.
- Folder READMEs: every folder under `src` has one (checked by `npm run check:readmes`); start at [src/game/README.md](../src/game/README.md) and [src/renderers/README.md](../src/renderers/README.md).

## Playing and clients

- [PLAYING.md](PLAYING.md): the opening in the terminal, then trade, diplomacy, tiers, homes, chronicle and standing orders.
- [CLI.md](CLI.md): terminal verbs, the JSONL protocol, the scenario format and the CLI tests.
- [UI.md](UI.md): the React and three.js client: running it, architecture, hooks, panels, screens and tests.
- [../scenarios/README.md](../scenarios/README.md): what each scenario file proves.

## Traceability and audit

- [FR-COVERAGE.md](FR-COVERAGE.md): generated by `npm run fr-coverage`; which requirement ids are named by a test and the uncovered list.
- [audit/](audit/): one file per spec (001 to 029, no 008) with FR-by-FR status, code, test and notes, and a Gaps section.
- [content-crossrefs-5.1.md](content-crossrefs-5.1.md): wiring left open by the terrain, material and furniture content (task 5.1).
- [content-crossrefs-5.2.md](content-crossrefs-5.2.md): recipes and zones; where the landed v0 records differ from the spec.
- [content-crossrefs-5.3.md](content-crossrefs-5.3.md): what the skills, needs, humanoids, factions, behavior trees and animals content still lacks (humanoid equipment, need satisfaction methods, zones of the religious factions, tree actions not modelled) and the skill-to-recipe link table.
- [content-crossrefs-5.4.md](content-crossrefs-5.4.md): the declared raw-material source gaps that the content conformance test reads.
