## Gaps

- SC-009: CI regression gate for >10% slowdowns is missing; `.github` is out of scope. Proposed: a CI step running `npm run perf` against a committed baseline in docs/PERFORMANCE.md.
- FR-009: no classes named CitizenQueries/FactionQueries/ResourceQueries; the composable `EntityQuery` plus domain query modules cover the intent. Proposed: no change unless the owner wants the names.
- SC-010: heap growth over 100,000 queries is not measured (only result stability).
