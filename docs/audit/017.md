## Gaps

1. Concurrency greater than 1: needs `concurrency` and `slotsFree` on the posting and several claimants per posting (`claimId`/`claimantId` become lists), which touches every executor; no job type needs it today. Proposed as a model change with a save migration.
2. Home board (FR-017): add an optional `homeBoardId` to `Citizen`, set at the last assignment, checked first by `findBoardToVisit` until a configurable number of empty visits.
3. System posters (`recurring` is only reachable through `PostCustomJob`); farm and zone posters could use it instead of re-posting by their own interval.
